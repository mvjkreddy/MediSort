# MediSort — Healthcare Triage & Hospital Intelligence System

## Overview
MediSort is an educational Java-based project that demonstrates basic patient registration, rule-based symptom assessment, and department recommendations.

## Technologies
- Java
- Java Swing
- MySQL
- JDBC

## Features
- Patient registration
- Symptom-based demo urgency assessment
- Suggested department
- Patient record search and refresh

## Important Note
The triage rules are for educational demonstration only. They are not clinically validated and must not be used to make real medical decisions.

## Project Status
Development and testing in progress.
